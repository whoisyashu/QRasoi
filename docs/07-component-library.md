# Component Rules

Every component must be reusable.

Every component must be typed.

Every component must have variants.

Every component must support loading state.

Every component must support disabled state.

Every component must support responsive layouts.

No page-specific components unless absolutely necessary.

Never duplicate buttons.

Never duplicate cards.

Never duplicate dialogs.
