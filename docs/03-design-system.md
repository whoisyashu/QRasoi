Inputs

Consistent height.

---

Cards

Rounded corners.

Soft shadow.

Consistent internal spacing.

Never different card styles on same page.

---

Icons

Only Lucide.

Consistent stroke width.

No mixed icon libraries.

---

Images

Rounded corners.

Optimized.

Lazy loaded.

Proper aspect ratio.

---

Animations

Purpose Driven.

Fast.

Subtle.

Natural.

No distracting effects.

---

Loading

Skeleton loaders.

Never spinner-only pages.

---

Empty States

Every empty page must explain

Why it is empty

What user should do next

Primary Action

---

Error States

Clear message.

Friendly language.

Recovery action.

Retry button when applicable.

---

Responsive Philosophy

Mobile First

Tablet Second

Desktop Third

Never desktop-first.

---

Accessibility

Keyboard Accessible

Proper Contrast

Semantic HTML

Visible Focus

Large Touch Targets

Readable Typography

---

Visual Consistency

Every page must look like it belongs to the same application.

No page should introduce a new visual style.

No experimental UI.

No redesigning existing components.
