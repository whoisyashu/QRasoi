# QRasoi Color Palette

This document defines the complete color system used across the application.

No additional colors should ever be introduced without updating this file.

---

## Design Philosophy

The application should feel

Warm

Friendly

Modern

Minimal

Restaurant Focused

Professional

The palette should create appetite while maintaining a clean SaaS appearance.

Avoid bright flashy colors.

Avoid neon colors.

Avoid gradients in application UI.

Gradients are allowed only on the Landing Page.

# Charts

Charts should only use the following palette.

Blue

Green

Orange

Purple

Gray

Never use random colors.

Never use rainbow charts.

Maximum five colors in one chart.

# Rules

Never use pure black.

Never use pure white backgrounds.

Never use random gradients.

Never hardcode colors.

Always use design tokens.

All colors must come from this document.
