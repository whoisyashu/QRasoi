# Animation Guidelines

Animations should improve usability.

Animations should never become decoration.

The application should feel smooth and responsive.

---

# Animation Libraries

Landing Page

GSAP

Application UI

Motion

Never mix animation libraries for the same interaction.

---

# General Rules

Animations must be short.

Animations must feel natural.

Animations must never delay user interaction.

Animations should support usability.

---

# Duration

200ms–300ms

Page Transition

300ms–400ms

Hero Animation

500ms–800ms

# Performance Rules

Animations must remain at 60 FPS.

Animate transform and opacity whenever possible.

Avoid layout thrashing.

Avoid expensive filters.

Avoid unnecessary re-renders.

---

# Accessibility

Respect reduced motion preferences.

Provide instant fallback for users who disable animations.

Animations must never block interaction.
